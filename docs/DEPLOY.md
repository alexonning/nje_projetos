# Deploy na Vercel

1. Envie o repositório ao GitHub.
2. Importe o projeto na Vercel.
3. Configure as variáveis Supabase somente quando a integração for implementada.
4. Execute o build e valide a aplicação antes de liberar em produção.
5. **Não publique esta prévia como sistema de produção**: ela ainda não possui autenticação, persistência real nem RLS.

Para execução local, veja o README.
